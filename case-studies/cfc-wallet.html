CFC Wallet Frontend Redesign

CFC Wallet handles airtime, data, utility bills, and wallet-to-wallet transfers across Nigeria. I was brought in with the existing React Native codebase and asked to redesign the entire frontend — cleaner navigation, better visual hierarchy, and a flow that doesn't make users hunt for the recharge button.

Design decisions

Visual system & rationale

The problem wasn't the features — it was findability. CFC Wallet had all the right services, but users had to hunt for them. The original design treated every action as equal, so buying airtime took the same number of taps as changing your PIN. The redesign establishes hierarchy: common actions are one tap from the home screen, less frequent tasks live in clearly labeled sections.

Color as meaning, not decoration. The pink-to-magenta gradient isn't arbitrary — it signals financial action. Transaction success is green, pending is orange, failed is red. Every color choice reinforces what's happening, so users don't have to read fine print to know if their recharge went through.

Cards over lists. The original design leaned on tables and vertical lists, which work on desktop but feel cramped on mobile. The redesign uses cards with breathing room, large touch targets, and enough whitespace that scanning is effortless even on a moving bus.

Search-first for services. When you're paying a cable bill or buying data, you know which provider you want. The redesign puts search at the top of every service screen, with recent and saved beneficiaries below, so repeat transactions take two taps instead of six scrolls.

Technical approach

Implementation & constraints

Frontend-only redesign. I was handed the React Native codebase with strict instructions: don't touch the backend, don't change the API calls, don't rewrite the state management. Every improvement had to happen in the component tree, styling, and navigation structure.

React Native with reusable components. Built a design system from scratch — button variants, card layouts, input fields, status badges — all parameterized so future screens could stay consistent without re-implementing from scratch. The pink gradient became a design token, not a hardcoded hex value scattered across 40 files.

Performance on budget devices. Most CFC Wallet users are on mid-range Android phones with intermittent connectivity. The redesign uses progressive loading, cached transaction history for offline viewing, and simplified animations that don't stutter on older hardware.

Accessibility baked in. Large touch targets (48×48dp minimum), high contrast text, and clear focus states for users navigating with TalkBack or Switch Access. The original design had 12px grey-on-grey labels; the redesign enforces WCAG AA contrast ratios across every screen.

Impact

Results & takeaways

Measurable improvements. After the redesign shipped, CFC reported a 28% reduction in support tickets related to "I can't find where to buy airtime" — the new home screen made common actions obvious. Average time-to-complete for a standard airtime recharge dropped from 38 seconds to 18 seconds, largely because users no longer had to scroll through a grid of 20 identical icons.

What I learned. Redesigning a live fintech app is high-stakes. Users aren't here to admire your UI — they're here to pay a bill or send money, and any confusion costs them time or money. The pink gradient and card layouts weren't about making the app "pretty"; they were about making every action legible at a glance, even in bright sunlight or with shaky hands.

Design is a forcing function for product clarity. The original app tried to do everything at once, so the interface was a mess. The redesign forced the team to answer: what do users do every day, and what's a once-a-month task? That hierarchy became the structure of the new design, and suddenly the app felt intuitive because it matched real usage patterns.
