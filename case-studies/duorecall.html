01. The Problem & Concept

What if studying didn't feel like a chore?

Traditional flashcard apps are rigid, clinical, and tedious. Memorizing complex formulas, dates, or vocabulary often feels like punishment rather than deliberate learning.

Inspired by Duolingo’s gamification principles, DUO Recall re-imagines flashcard revision by combining instant visual feedback, streak tracking, and fluid gesture controls into a lightweight mobile interface.

02. Engineering & Architecture

Offline-first, modular, and fast

DUO Recall was engineered with React Native, Expo, and TypeScript for maximum performance across cross-platform mobile environments. Data is managed entirely offline using AsyncStorage, giving users 100% data ownership and instant card load times without server latency.

Custom Decks

Create and categorize flashcard decks for any subject area—medical terms, history, or code snippets.

CSV Bulk Sync

Import massive study decks via CSV files automatically, removing manual data entry bottlenecks.

Interactive Flip Engine

Responsive, touch-optimized card flipping logic engineered for quick recall tests on mobile screens.

Progress & Streaks

Track study streaks, session accuracy, and card mastery using local analytical state tools.

100% Offline Privacy

Zero cloud latency or forced user accounts. All decks remain encrypted and stored locally on-device.

Gamified Feedback

Rewarding visual cues and streak rewards designed to increase study consistency and retention.

03. Project Impact

“The most effective developer projects are the ones that solve real personal problems with production-grade engineering standards.”

DUO Recall serves as a functional demonstration of modern mobile UI execution, state management, and offline architecture, bridging the gap between engaging game mechanics and practical utility.
