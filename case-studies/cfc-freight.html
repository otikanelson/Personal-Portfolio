Mobile App Redesign

Project Context

The same client, a different challenge

CFC Freight was a redesign project for the same organization behind CFC Wallet and part of the AFROCHINATRADE ecosystem. The original app worked, but the interface didn't match the complexity of managing freight logistics across multiple stakeholders.

The challenge wasn't just visual—it was about rethinking how shippers, carriers, and forwarders interact with shipment data, documentation, and fleet tracking in real time.

The Problem

Logistics is chaos by default

Shipments delayed. Documents lost. Drivers and managers playing phone tag. The freight industry runs on coordination, but the tools often make coordination harder, not easier.

The original CFC Freight app had the functionality—quote automation, shipment tracking, document uploads, fleet monitoring—but the UI made navigating all of that feel overwhelming.

The Redesign

Clear structure, better flow

I redesigned the interface with a focus on role-based workflows. Shippers see shipment status and quotes. Carriers see routes and documentation. Forwarders see coordination tools. Everyone gets what they need without wading through irrelevant features.

Built with React Native and TypeScript for cross-platform consistency. The redesign focused on information hierarchy, intuitive navigation, and reducing cognitive load for users managing multiple shipments simultaneously.

Automated Quotes

Generate shipping quotes instantly based on routes, weight, and service type.

Real-Time Tracking

Monitor shipments in transit with live location updates and ETAs.

Document Management

Upload, store, and share bills of lading, invoices, and customs forms.

Fleet Monitoring

Track vehicle locations, driver status, and delivery schedules.

Multi-Stakeholder Views

Role-based interfaces for shippers, carriers, and freight forwarders.

Smart Notifications

Alerts for shipment updates, delays, documentation needs, and delivery confirmations.

Design Approach
Good logistics software should make coordination invisible. Users shouldn't think about the interface—they should think about the shipment.

This redesign taught me that functional software isn't enough. When users are managing high-stakes operations—freight, money, deadlines—the interface has to reduce stress, not add to it.
