SCENORY

Storyboarding & Art Application

JavaFX MySQL MVC Architecture IntelliJ

This was built to help an animator and creative friend of mine create faster and easily. Storyboarding shouldn't feel like a chore. SCENORY is a canvas where ideas flow—drag panels, sketch scenes, add notes, zoom in on details. Whether you're planning a film, designing a game, or mapping out a visual story, everything you need is right here. Save your work, come back anytime, and bring your vision to life panel by panel.

Key Features

  • Zoom/pan canvas with drag-and-drop panels
  • Comprehensive drawing tools (shapes, lines, text)
  • Color palette and eraser functionality
  • MySQL persistence for project management
  • MVC architecture with command pattern
  • Glass-morphism UI design
